# Nathan Mendis Portfolio & Blog

A modern portfolio and blog website built to showcase projects, technical skills, and development work through a clean and interactive user experience.

The project features a Valorant-inspired UI with cinematic animations, responsive layouts, and a decoupled full-stack architecture using React and Django REST Framework.

---

# 🛠 Tech Stack

## Frontend

- React (Vite)
- Tailwind CSS v3
- Framer Motion
- React Router DOM
- Axios

## Backend

- Django
- Django REST Framework
- PostgreSQL / SQLite
- Google OAuth2
- Python Dotenv

---

# 🚀 Features

- Responsive modern portfolio website
- Valorant-inspired UI design
- Interactive hero section with parallax effects
- 3D cards and smooth animations
- Dynamic blog integration using REST APIs
- Project showcase carousel
- Secure contact form with Gmail OAuth2
- Decoupled frontend and backend architecture
- Mobile-friendly responsive layout

---

# 🎨 UI & Design

The website is designed with a futuristic gaming-inspired aesthetic featuring:

- Glassmorphism UI elements
- Animated transitions
- Motion-based interactions
- Clean responsive layouts
- Modern typography and HUD-inspired components
